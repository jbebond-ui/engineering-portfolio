# James Ly Engineering Portfolio

Source repository for James Ly's engineering portfolio.

## Direction

A refined engineering field-notebook aesthetic: editorial, technical when useful, and slightly quirky without becoming gimmicky.

## Current content scope

- Custom UAV / UAS work
- BGE engineering highlights
- SIMPLE|HUMAN highlights
- Drexel mechanical engineering projects
- Reliability and validation
- Automated test rigs and data pipelines
- Factory QA standardization
- FEA and mapping / data automation

Tesla and Nanotronics are intentionally excluded from this portfolio.

## Site goals

1. Recruiter-readable in under 30 seconds.
2. Show engineering decisions and evidence, not repeat a resume.
3. Use project case studies for deeper technical detail.
4. Keep the site lightweight, responsive, and accessible.
